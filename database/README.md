# Banco de dados

Este diretório é reservado para futuras migrations, consultas de manutenção e documentação.

O projeto usa o banco existente `practice_day`. Nenhum script de criação, alteração de tabelas ou dados foi incluído aqui.

`test_connection.php` é um teste de terminal que executa apenas `SELECT DATABASE()` para confirmar a conexão configurada. Ele não cria, altera nem consulta dados de tabelas.
